This is to be a Swiss Army Knife for SOC Analysts and security researchers to use for scanning Android devices with YARA and Sigma rulesets as well as having a ClamAV engine and signature databases. Eventually I will add a Quarantine feature and API integration for services like VirusTotal and HybridAnalysis threat intelligence.
